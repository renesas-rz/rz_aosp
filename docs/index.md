# RZ MPU Software Package for AOSP

<div class="grid" markdown>

<div markdown>
The RZ MPU Software Package for AOSP provides an open-source software platform based on the [Android™ Open Source Project (AOSP)](https://source.android.com/){: target="_blank" } for Renesas RZ MPUs, including platform software, device support, graphics, and multimedia functionality.

To get started quickly, please refer to the Quick Start Guides. To build and customize the software platform from source code, please refer to How to Build RZ AOSP from Source Code.

<small>_Android is a trademark of Google LLC._</small>

## Available Releases

* v17.0.0 (AOSP 17)
    * Supported RZ MPUs: RZ/G3L
    * See [Introduction to the RZ/G3L Software Package for AOSP 17](https://renesas-rz.github.io/rz_aosp/v17.0.0/introduction/)
* v15.3.0 (AOSP 15)
    * Supported RZ MPUs: RZ/V2H
    * See [Overview of the RZ/V2H Software Package for AOSP 15](https://renesas-rz.github.io/rz_aosp/v15.3.0/)
* v14.5.1 (AOSP 14)
    * Supported RZ MPUs: RZ/G3E
    * Documentation is available in the software package distributed through the [Software & Tools for RZ/G3E](https://www.renesas.com/products/rz-g3e?tab=software-tools&softwareAndTools=true){: target="_blank" }. A direct download link is also provided below:<br />
