### **Note**

| No. | Note |
| :---: | :--- |
| 1 | <span style="color:red">**Important note:**</span> This RZ AOSP only supports arm64-v8a (64-bit only) as primary architecture. No secondary architecture (**armeabi-v7a**) (32-bit) support. So, users can only install applications which support **arm64-v8a**. |
| 2 | It’s <span style="color:red">**NOT**</span> recommended to hot-plug HDMI. It may cause the board broken. |

| 5 | It's required to plug external power if users use external devices like portable monitor, USB hub..., etc. |
